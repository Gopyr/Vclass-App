# Security Policy

Please do not publish credentials, tokens, private URLs, or proof-of-concept exploit details in a public issue. If GitHub Security Advisories are enabled for this repository, use a private advisory. Otherwise, contact the maintainer through the GitHub profile and provide a concise description, affected version or commit, reproduction conditions, and a suggested mitigation.

Security reports are reviewed on a best-effort basis. This project does not promise a particular response time or support level.
